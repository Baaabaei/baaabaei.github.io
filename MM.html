درباره منAbout

بیش از شش سال در توسعه نرم‌افزار کار کرده‌ام و تخصص اصلی‌ام Java و Spring Boot است. سرویس‌های Backend و RESTful API را روی PostgreSQL، MySQL و SQL Server طراحی و پیاده‌سازی می‌کنم. در نرم‌افزارهای دسکتاپ با JavaFX، اپلیکیشن‌های Android با Kotlin، Java و Flutter و Frontend با HTML، CSS و JavaScript هم تجربه دارم.

با Python و مفاهیم یادگیری ماشین و شبکه‌های عصبی آشنا هستم. تدریس برنامه‌نویسی و ICDL به من کمک کرده مفاهیم فنی را برای سطوح مختلف ساده منتقل کنم. به نرم‌افزار باکیفیت، قابل نگهداری و مقیاس‌پذیر علاقه دارم.

I have spent 6+ years building software, with Java and Spring Boot as my core. I design and ship backend services and RESTful APIs on PostgreSQL, MySQL and SQL Server, and I have also worked on JavaFX desktop apps, Android apps (Kotlin, Java, Flutter) and frontends in HTML, CSS and JavaScript.

I am familiar with Python, machine learning and neural networks. Teaching programming and ICDL taught me to explain technical ideas to people at every level. I care about quality, maintainable, scalable software.
